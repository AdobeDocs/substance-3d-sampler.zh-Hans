# 生成器

生成器是对素材进行添加更改的滤镜。 生成器通常导致素材的外观发生显着变化，因此经常用于创建素材的基础。

发电机的主要形式有两种：

* 转换生成器将底层素材转换为新形式，如使用&#x200B;**面板过滤器**&#x200B;将扁钢素材转换为多个面板。
* 添加生成器会在基础素材上方添加新元素，如&#x200B;**Atlas Scatter筛选器**，该筛选器从输入地图集中跨素材散点对象。

转换生成器包括：

* [墙砖](brickwall.md)
* [地板拼贴](floor-tiles.md)
* [面板](panel.md)
* [镶板](parquet.md)
* [人行道](pavement.md)
* [面组拼接](quilt-stitch.md)
* [石墙](stonewall.md)
* [表面浮雕](surface-relief.md)

添加生成器包括：

* [Atlas Scatter](atlas-scatter.md)
* [贴纸](decal.md)
* [浮雕](embossing.md)
* [刺绣](embroidery.md)
* [砾石](gravel.md)
* [图案](pattern.md)
* [穿孔](perforate.md)
* [飞溅](splatter.md)
* [织造](weave.md)
* [布料编织](cloth-weave.md)
