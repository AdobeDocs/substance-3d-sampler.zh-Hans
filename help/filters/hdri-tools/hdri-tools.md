# HDRI 工具

>[!IMPORTANT]
>
> 未来更改
> 
> Sampler V5.2版本将不再支持环境光和网格。 删除环境光还包括删除HDRI 工具和滤镜。

“HDRI 工具”部分中的过滤器是专门用于处理环境光的工具。 HDRI表示高动态范围图像，但通常用于引用用于创建环境光的全景图像。 由于在传统软件中修改全景图像可能很困难，因为球面3D信息必须映射到2D图像文件 — 在Sampler中的HDRI 工具设计时考虑到了这一点，因此在HDRI中修补和添加光照会更加容易。

以下过滤器为HDRI 工具：

* [Exposure](exposure.md)
* [曝光度预览](exposure-preview.md)
* [HDR 合并](hdr-merge.md)
* [线光源](line-light.md)
* [Nadir Extract](nadir-extract.md)
* [Nadir Patch](nadir-patch.md)
* [全景修补](panorama-patch.md)
* [平面光](plane-light.md)

* [球面光](sphere-light.md)
