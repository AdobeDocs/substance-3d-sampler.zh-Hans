# 导入资源

Sampler可以使用图像和Substance文件等外部资源来修改您的项目。 使用以下任一选项将文件导入项目：

* 将文件从文件资源管理器拖放到Sampler窗口中。 此时会显示一个导入窗口，其中包含用于更改导入处理方式的选项。

![](../assets/importing-resources-Importwindow.png)

* 从<b>左栏</b>中使用<b>获取内容</b>按钮，然后选择<b>在图层栈栈中导入</b>或<b>导入您的资源</b>。 这两个选项都将打开一个文件资源管理器，您可以在其中导航并选择要导入的一个或多个文件。
  * <b>在图层栈栈中导入</b>导入当前项目的文件。
  * <b>导入您的资源</b>导入该文件，以便可以从任何项目访问它。

![](../assets/Project_CreateNew.png)

* 在<b>图层</b>面板中，如果未创建任何图层，则可以使用可用的链接导入文件，以构成素材的基础。

>[!NOTE]
>
> 资源是链接资源，而不是导入资源。 因此，如果移动或删除资源文件，则使用该资源创建的材料或内容将受到影响。 因此，我们建议对Sampler Assets使用专用文件夹。
> 
> 默认情况下，Sampler包含的资源存储在C:\Program Files\Adobe\Adobe Substance 3D Sampler\Resources\assets下

## 支持的文件格式

| 类型 | 描述 |
| --- | --- |
| <b>位图/图像</b>（JPEG、PNG等） | 您可以在<b>图层</b>面板中拖放或导入位图，或者将其导入允许图像输入的SBSAR或滤镜参数。 |
| <b>Substance包</b> (SBSAR) | 可将SBSAR文件导入<b>资源</b>面板或<b>图层</b>面板。 |
