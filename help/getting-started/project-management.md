# Project management

在Substance 3D Sampler中，您可以使用收藏集来管理所有资源和材料。 项目是整理材料的好方法。 项目可以导出或导入，以便在计算机之间轻松共享。

## 创建新项目

要创建新项目，请在&#x200B;**主页**&#x200B;屏幕中选择&#x200B;**新建**&#x200B;或&#x200B;**文件>新建项目**。 创建新项目将启动“快速启动”对话框，您可以在其中选择[快速操作](../features-and-workflows/quick-actions.md)或导入图像或Substance文件以启动项目。

>[!TIP]
>
> 如果您不熟悉Sampler，[快速操作](../features-and-workflows/quick-actions.md)可以帮助您快速入门，方法是详细了解Sampler可以帮助您实现的目标。

![](../assets/6.0_HomeScreenFocus.png)

或者，您可以使用&#x200B;**快速入门**&#x200B;按钮直接跳到一个空项目。 您仍可以根据需要手动导入资源和内容。

单击“新建”按钮后，将自动打开项目并将其命名为“*无标题项目\**”，直到您保存项目为止。 您可以使用&#x200B;**项目面板**&#x200B;中突出显示的&#x200B;**“新建资源”按钮**&#x200B;将资源添加到项目中。

![](../assets/Project_CreateNew_1.png){width="600px"}

## 保存项目

若要保存项目，请使用&#x200B;**文件>保存**&#x200B;或&#x200B;**另存为**&#x200B;菜单操作。 此时将打开一个对话框，供您选择要使用哪个名称以及保存项目文件的位置。

或者，您可以使用&#x200B;**Ctrl + S**&#x200B;快捷键到&#x200B;**保存**&#x200B;或&#x200B;**Ctrl + Shift + S**&#x200B;订阅&#x200B;**另存为**。

保存的项目显示为名为&#x200B;**YourProject.ssa**&#x200B;的文件。 SSA是取样器文件格式，用于存储有关您的项目及其可能具有的任何依赖项的信息。

## 打开现有项目

可通过多种方式打开项目：

* 在&#x200B;**主屏幕**&#x200B;中：使用最近打开的项目列表，通过双击项目来快速打开它。
* 在&#x200B;**主屏幕**&#x200B;中：单击&#x200B;**打开**&#x200B;以打开文件浏览器，您可以在其中选择要打开的文件。
* 通过&#x200B;**文件>打开项目**&#x200B;菜单。
