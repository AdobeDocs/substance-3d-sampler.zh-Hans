# Project management

在Substance 3D Sampler中，您可以使用收藏集来管理所有资源和素材。 项目是组织素材的好方法。 项目可以导出或导入，以便在计算机之间轻松共享。

## 创建新项目

要创建新项目，请在<b>主页</b>屏幕中选择<b>新建</b>或<b>文件>新建项目</b>。 创建新项目将启动“快速启动”对话框，您可以在其中选择快速操作或导入图像或Substance文件以启动项目。

![](../assets/6.0_HomeScreenFocus.png)

或者，您可以使用<b>快速入门</b>按钮直接跳到一个空项目。 您仍可以根据需要手动导入资源和内容。

单击“新建”按钮后，将自动打开项目并将其命名为“*无标题项目\**”，直到您保存项目为止。 您可以使用<b>项目面板</b>中突出显示的<b>“新建资源”按钮</b>将资源添加到项目中。

![](../assets/Project_CreateNew_1.png){width="600px"}

## 保存项目

若要保存项目，请使用<b>文件>保存</b>或<b>另存为</b>菜单操作。 此时将打开一个对话框，供您选择要使用哪个名称以及保存项目文件的位置。

或者，您可以使用快捷键<b>Ctrl + S</b>到<b>保存</b>或<b>Ctrl + Shift + S</b>到<b>另存为</b>。

保存的项目显示为名为<b>YourProject.ssa</b>的文件。 SSA是取样器文件格式，用于存储有关您的项目及其可能具有的任何依赖项的信息。

## 打开现有项目

可通过多种方式打开项目：

* 在<b>主屏幕</b>中：使用最近打开的项目列表，通过双击项目来快速打开它。
* 在<b>主屏幕</b>中：单击<b>打开</b>以打开文件浏览器，您可以在其中选择要打开的文件。
* 通过&#x200B;**文件>打开项目**&#x200B;菜单。
