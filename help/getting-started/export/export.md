# 导出

您可以通过选择&#x200B;**“文件”菜单**&#x200B;中的&#x200B;**“导出为”**，或按快捷键&#x200B;**Ctrl + E**&#x200B;来导出资源。这将打开[导出窗口](../../getting-started/export/export-window/export-window.md)，您可以在其中自定义导出。

>[!NOTE]
>
> 在&#x200B;**导出窗口**&#x200B;中，更改材质模型选项将更改导出的文件名以匹配所选材质模型。

![已选择材料设置的“导出”窗口](../../assets/6.0_ExportWindowMaterialSettings.png)

Sampler支持资源的主要文件格式：

* 材料可以导出为&#x200B;**SBS**&#x200B;或&#x200B;**SBSAR**&#x200B;文件。
* 或者，也可以使用以下文件格式导出每通道材料位图纹理：
  * **EXR**
  * **JPEG**
  * **PNG**
  * **TARGA**
  * **TIFF**
  * **USDA**
  * **USD**
  * **USDZ**
