# 常见问题解答 — 常见问题解答

## Beta版访问权限

* **如何访问Beta版&#x200B;？** \
  现有Substance 3D客户可以使用其Adobe ID登录Creative Cloud桌面，并在Beta部分找到他们。&#x200B;
* **Steam版本是否可以访问Beta版应用程序？{&#x200B;1}**\
  Beta版仅适用于Substance订阅者。

## Adobe、Firefly和生成式AI

[访问完整的Firefly常见问题解答](https://www.adobe.com/cn/products/firefly.html#faqs)

* **作为Adobe客户，Firefly模型中是否包含我的内容的副本？** \
  不，Firefly模式中不包括客户内容的副本。
* **作为Adobe客户，我的内容是否会自动用于培训Firefly？** \
  不行。 我们不会针对任何Creative Cloud订阅者的个人内容进行培训。 根据Stock投稿人许可协议，对于Adobe Stock投稿人，内容是Firefly培训数据集的一部分。
* **Adobe是否计划对内容在数据集中使用以训练Firefly模型的Adobe Stock投稿人进行报酬，以及报酬计划的外观？** \
  我们建立了Adobe Stock投稿人的薪酬模型。 有关更多信息，请参阅Adobe Stock常见问题解答。
* **Adobe正在采取哪些措施来确保AI生成的图像是负责任地创建的？** \
  为了将Firefly设计成商业上安全的Adobe，我们正在对初始的商业Firefly模型进行培训，内容涉及许可内容（例如Adobe Stock）和版权已过期的公共域内容。 此外，作为“内容真实性计划”(CAI)的创始合作者，Adobe正在为负责任的生成式AI制定行业标准。 CAI是一个由媒体和科技公司、非政府组织、学者和其他组织组成的社区，致力于推动采用内容真实性和来源的开放行业标准。
* **什么是Adobe Firefly Image 2模型？** \
  Adobe Firefly图像2是模型Firefly系列中的下一个图像生成模型版本。
