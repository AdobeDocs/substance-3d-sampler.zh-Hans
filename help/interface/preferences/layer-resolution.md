# 图层分辨率

图层分辨率系统可让您完全控制图层栈栈中每个图层的分辨率。 图层可以采用您的文档大小的分辨率，也可以采用下方图层的分辨率。

分辨率显示在每个图层上，可轻松直观地看到您的材质分辨率将如何影响任何作品。

这样，您就可以提高材料的质量，但要注意，较高的分辨率可能会影响在处理资源时的性能。

![显示图层分辨率的“图层”面板和“属性”面板](../../assets/LayersPanelAndPropertiesPanel.png)

只需单击一下，您即可从工作分辨率切换到更高的分辨率，以可视化准备好导出的最终素材。

![切换所有图层分辨率](../../assets/Switch_All_Resolution.gif)
