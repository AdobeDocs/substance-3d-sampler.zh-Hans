# 2D和3D视口

![](../assets/main-3d-viewport-5.png)

**视区**&#x200B;显示您当前的资源。 在&#x200B;**视口**&#x200B;**1&rbrace;的顶部，您可以看到资源的名称以及用于更改**&#x200B;视口&#x200B;**外观的选项。 &#x200B;** 使用这些选项可以：

* 更改资源的宽度和Height（以像素为单位）。
* 显示<b>2D视图</b>、<b>3D视图</b>或同时显示<b>2D </b>和<b>3D视图</b>。
* 将<b>拆分视图</b>切换到水平显示。
* 交换<b>3D和2D视图</b>。
* 在标准视口和全屏视口之间切换。

![](../assets/screenshot-2023-01-25-at-16-23-09.png)

## 3D 视图

<b>3D视区</b>有两个工具栏，可用于更改资源在<b>视区</b>中的显示方式。 默认情况下，这些工具栏显示在右上角和<b>3D视口</b>的底部中心。

![] ()

>[!NOTE]
>
> 可以重新定位<b>3D视口</b>工具栏：
> 
> * 通过拖动工具栏顶部或左侧的手柄，可以移动工具栏。
> * 双击工具栏顶部或左侧的手柄可在水平和垂直布局之间切换。
> * 单击工具栏底部或右侧的双V形以最小化工具栏。

<b>3D视区</b>右上角的工具栏中包含侧重于视区外观的控件：

* <b>视图</b>：更改相机设置，如视场或投影模式。 此外，更改网格和背景颜色。
* <b>网格</b>：选择其他网格以显示您的素材资源，或查看环境光资源的细微差别。
* <b>材质</b>：更改纹理在网格上的位置和拼贴。
* <b>位移</b>：调整位移质量和强度。
* <b>光线</b>：选择并调整环境光线，包括打开阴影和地平面等设置。
* <b>切换路径描摹</b>：路径描摹是一种渲染技术，可提供逼真的效果，从而改善资源的外观。 但是，路径跟踪的计算成本可能很高，您可以根据需要打开或关闭路径跟踪。

>[!NOTE]
>
> 打开“阴影”以改进视口视觉效果。 关闭阴影以提高Samplers性能。

![] ()

<b>3D视口</b>底部中心的工具栏具有以下信息和控件：

* <b>帧时间/FPS</b>：这些值显示素材的性能。
* <b>框架对象</b>：将相机置于网格的中心。
* <b>向上更改轴</b>：更改将哪个轴视为向上。 这有助于更正导入网格的问题。
* <b>放置</b>：更改网格相对于地平面的位置。
* <b>复制快照</b>：将当前<b>3D视口</b>的图像快速复制到剪贴板。
* <b>保存快照</b>：将<b>3D视口</b>的快照保存到图像文件。
* <b>3D视图控件</b>：查看3D视口中相机控件的快速参考。

![] ()

## 移动相机

视区使用摄像机渲染3D视图。 您可以移动相机以改变视图，并从不同角度查看您的创作。

| 快捷键 | 运动 | 描述 |
| --- | --- | --- |
| 单击并拖动 | 环绕 | 旋转相机。 无法滚动相机。 |
| 单击右键并拖动 | 推拉 | 前后移动相机。 |
| 中键单击并拖动 | 平移 | 向左、向右、向上和向下移动相机。 |

<b>2D视图</b>是二维的，因此没有轨道选项。 单击右键+ Alt +拖动可放大和缩小，单击中键+ Alt +拖动可平移。

在<b>3D视图</b>和<b>2D视图</b>中，使用<b>F</b>聚焦您的资源。 如果您看不到3D资源或2D空间，这将很有帮助。

## 2D 视图

![] ()

默认情况下，只有<b>3D视图</b>可见，但是<b>2D视图</b>可以包含许多对某些滤镜有用的信息和控件。

要打开<b>2D视图</b>，请使用视口右上角的<b>视图选择按钮</b>。 您还可以使用快捷键<b>2</b>快速切换到<b>2D视图</b>。

在<b>2D视图</b>打开时，会显示一些新选项：

* 在&#x200B;**2D视图**&#x200B;的右上角，使用下拉菜单更改可查看的可用声道源。

  * “图层输入”显示输入到选定图层的通道
  * 图层输出显示选定图层输出的通道
  * “素材输出”显示由顶层图层输出且不受图层选择影响的通道。
* 在&#x200B;**2D视图**&#x200B;的底部，您可以：

  * 查看所选通道的分辨率。
  * 选择通道以在 2D 视图中进行查看。
  * 请参阅所选素材通道的颜色通道和位深度。
