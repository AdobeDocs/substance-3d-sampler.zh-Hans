# 滑块

![](../../assets/sliders-basic.gif)

有一个选项可以对一个到多个滑块进行动画制作。 将鼠标悬停在滑块上时按&#x200B;**Ctrl**，将显示&#x200B;**播放**&#x200B;图标以启动动画。

将鼠标悬停在动画滑块上时，按&#x200B;**Ctrl**&#x200B;可暂停动画，此时将显示&#x200B;**暂停**&#x200B;图标以停止此滑块的动画。

如果要暂停所有滑块，请按&#x200B;**P**。要重新启动，请再次按&#x200B;**P**。
