# 材料创建预设

材料创建模板为具有高级物理行为的建筑材料提供了预定义的起点。 每个模板均配置特定类型表面所需的材质模型、启用的通道和默认参数，从而允许您在完全控制结果的情况下快速创建复杂材料。 模板在创建新材料时可用，可与OpenPBR和ASM材质模型一起使用。

![创建新材质窗口](../../assets/6.0_materialPresets.png)

>[!TIP]
> 您可以在[此处](../../features-and-workflows/create-advanced-materials/advanced-materials.md)了解有关创建利用模糊、亚表面和涂层通道的高级材料的更多信息。

## 从模板创建材料

要使用模板创建材料，请执行以下操作：

打开“创建新材质”对话框。 从“预定义”或“自定义”选项卡中选择模板。 调整材质设置（名称、分辨率、材质模型、声道）。 单击创建以开始使用配置的材料。

所选模板定义素材的初始结构，包括启用哪些通道以及在图层栈栈中设置通道的方式。

## 预设类别

### 预定义模板

预定义模板是现成的材料设置，旨在覆盖常见的物理材料行为。 它们为每种用例的最佳实践和建议的通道配置编码。 可用的预定义模板包括：

- 基础材质启用常用通道的标准基于物理的材料。 您可以将此模板用于不需要特殊行为的简单或通用材料。

- 各向异性：配置方向相关反射的材料，适用于拉丝金属或具有定向微细节的表面。

- 涂层：在基础材质顶部添加二次反射层，实现透明涂层或类似清漆的效果。

- Fuzz — 用于具有柔和外观的织物、纤维或材料的柔和的光散射表面效果。

- 亚表面：激活诸如蜡、塑料或有机表面等材料的亚表面光传输，其中光在表面下方穿透。

- 透明：配置用于光传输的材料，适用于类似玻璃或薄的透明材料。

每个预定义的预设会自动设置所需的通道和默认值，从而减少手动设置和技术复杂性。

### 自定义预设

自定义预设允许您重复使用自己的材料配置。 您创建的任何材质预设都可以另存为自定义模板，并显示在“自定义”选项卡中。 这支持使用共享标准和渠道配置跨项目或团队创建一致的材料。

## 预设详细信息

预设详细信息面板显示并控制用于创建新材料的设置。

### 资源名称

定义将创建的材料资源的名称。

### 解决方法

控制材料映射的默认分辨率（宽度和Height）。 创建材料时，此分辨率适用于所有已启用的声道。

### 材质模型

指定材料使用的材质模型：

基于物理的现代标准化工作流ASM的OpenPBR，与现有管道兼容

所选模板将适应所选材质模型。

### 添加基础材质

启用后，Sampler将使用与所选填充图层兼容的基础材质创建基本模板。 这样可以立竿见影地看到效果，而且是一个有用的起点。 该基础材质适用于OpenPBR和ASM材质模型。

### 应用预设缩略图值

启用后，将使用用于生成材料预览缩略图的值初始化模板，而不是中性默认值。 这有助于演示模板的预期行为，并有助于建立一个可以开始构建的视觉基础。

### 编辑列表

在创建材料之前，单击&#x200B;**编辑列表**&#x200B;以自定义频道集。 您可以根据需要启用或禁用通道，或将配置另存为新的自定义模板。
