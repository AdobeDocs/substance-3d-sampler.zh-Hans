# “项目”面板

![](../../assets/Project-panel-gen.png)

Sampler中的项目类似于可存储多个资源的包。 **项目面板**&#x200B;显示组成当前项目的材料。

“项目”面板顶部的控件允许您在当前项目中添加或管理材料：

* 使用&#x200B;**“添加”**&#x200B;按钮打开&#x200B;**“材质预设”菜单**，并将新材料添加到您的项目。
* 使用“**复制**”按钮可复制当前选定的材料。
* 使用“**重命名**”按钮重命名当前选定的材料。
* 使用&#x200B;**删除**&#x200B;按钮可删除当前选定的材料。

>[!NOTE]
>
> 您也可以右键单击任何材料以重命名、删除或复制它。

单击其中一个资源以将其加载到&#x200B;**视口**&#x200B;中，或将材料拖到&#x200B;**图层面板**&#x200B;上以在其他材料中使用。
