# “属性”面板

![属性面板](../../assets/Properties-panel-gen.png)

**“属性”面板**&#x200B;显示您在&#x200B;**“图层”面板**&#x200B;中选择的图层的参数和属性。 了解参数作用的最佳方法是试用它们，看看它们对您的资源有何影响。

显示在&#x200B;**“属性”面板**&#x200B;中的参数取决于您在&#x200B;**“图层”面板**&#x200B;中选择的内容。 有时，一个图层可以具有多组可自定义属性，例如，不在栈叠底部的素材图层将具有混合属性。 图层栈栈中的每个图标都是一组不同的属性和参数。 对于同时具有素材属性和混合属性的素材图层，该图层上将有两个图标。

## 应用于……

使用&#x200B;**属性面板**&#x200B;的&#x200B;**应用于**&#x200B;部分可以控制当前图层影响哪些通道。 与其他属性一样，根据图层或混合处于选中状态，通道设置会有所不同。

![通过属性通道的“应用于……”部分，可以控制当前滤镜影响的通道。](../../assets/6.0_AppliedTo.png)

默认情况下，会为大多数素材和滤镜打开所有通道。 某些滤镜（如“亮度”或“自然饱和度”）只会影响单个通道。 当滤镜仅影响单个通道时，您可以在图层名称旁边看到受影响的通道。

![带下划线的通道标注的“图层”面板屏幕截图。](../../assets/6.0_LayerChannelSpecifier.png)
