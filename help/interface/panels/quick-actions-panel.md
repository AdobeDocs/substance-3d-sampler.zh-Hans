# 快速操作面板

![](../../assets/quickactionpanel.png)

[快速操作](../../features-and-workflows/quick-actions.md)包含一系列功能和工作流，您只需点击几下即可执行强大的操作。 使用快速操作创建材料、创建项目或将所需的图层添加到现有堆叠。

在快速操作面板中，单击快速操作以将其添加到堆叠或创建新资源，具体取决于快速操作类型。 快速操作分为以下类别：

* **最近**：访问最近使用的快速操作。
* **处理图像**：导入、转换或调整图像。
* **改进材料扫描**：对齐、优化或平铺扫描的材料以获得更好的结果。
* **从图像创建材料**：将必要的图层添加到图层堆叠以将一个或多个图像转换为材料。
* **从头开始创建材料**：使用起始图层创建新的材料资源。

将鼠标悬停在快速操作上时，您可以使用显示的选项按钮，显示如下：

* **将**&#x200B;快速操作应用于图层堆叠。
* **设置**&#x200B;通过对话框执行快速操作。
* **使用选定的快速操作创建新资源**。
* **使用所选快速操作创建新项目**。
