# “着色器设置”面板

![](../../assets/Shader-settings-panel-gen.png.img.png)

在<b>着色器设置面板</b>中，您可以配置着色器在3D视口中渲染网格上资源的方式。

## 材质参数

材质参数允许您调整着色器渲染当前材质的方式。

| 参数名称 | 描述 |
| --- | --- |
| 法线强度 | 调整法线图的强度或强度。 |
| 合并法线和高度 | 切换是否将Height和法线图组合到单个映射中。 |
| 高度水平 | 更改Height的基本级别。 |
| 自发光强度 | 调整emissive地图的强度。 |
| 次表面散射 | 打开或关闭“子表面散射”。 |
| 折射指数 | 调整光线从表面折射的角度。 |
| 涂层折射指数 | 调整光线从表面皮毛折射出来的角度。 |
| 涂层法线强度 | 专门为表面涂层调整正常比例。 |
