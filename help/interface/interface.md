# 界面

Sampler的工作区由2D和3D视口、左右侧边栏以及一系列面板组成。 每个面板都专用于特定目的，因此不同的面板在创作过程的不同部分都很有用。

A. <b>应用程序菜单栏</b>显示当前项目名称。 它还包含“文件”、“编辑”、“窗口”、“帮助”和“许可证”菜单。\

* 在Creative Cloud桌面上浏览3D资源。

* 打开&#x200B;**声道设置面板**。

## 自定义工作区

Sampler的工作区是完全可自定义的，因此您可以找到最适合您的布局。 如果要将面板重置为默认布局，请使用&#x200B;**窗口>重置为默认布局**。

## 重新排列面板

单击并拖动面板的标题以开始移动它。

您可以将面板停靠在视口的边缘或其他面板上：将面板拖到要停靠的边缘上，这样就会出现一个蓝色的突出显示参考线。 看到这行时，请放下面板进行停靠。

## 打开和关闭面板

使用面板右上角的X可将其关闭。 已关闭的面板存储在侧边栏中。

要再次打开某个面板，请单击左侧或右侧边栏中该面板的相关图标。 这会暂时打开面板。 拖出面板以使其永久打开。

## 应用程序菜单

**应用程序菜单栏**&#x200B;显示当前项目名称。 它还包含&#x200B;**文件**、**编辑**、**窗口**、**帮助**&#x200B;和&#x200B;**许可证**&#x200B;菜单。

使用<b>文件</b>菜单创建新项目、打开现有项目或保存或导出当前项目。

使用<b>编辑</b>菜单可撤消和重做操作或打开[首选项](../interface/preferences/preferences.md)。

使用<b>窗口</b>菜单将工作区重置为默认布局。

使用<b>帮助</b>菜单了解有关Sampler的详细信息或了解如何修复问题。
