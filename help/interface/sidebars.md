# 侧边栏

Sampler有两个边栏，**左侧边栏**&#x200B;和&#x200B;**右侧边栏**。

![](../assets/Sidebars.png.img.png)

## 左侧边栏

在&#x200B;**左侧边栏**&#x200B;中，您可以：

* **添加和导入内容**：导入图像并选择应如何将其集成到您的项目中。
* **浏览3D资源**：从Creative Cloud桌面内的Substance 3D Assets访问数千个材料。
* 访问&#x200B;**快速操作**：用于快速实现特定目标的操作集合。 [了解有关&#x200B;**快速操作&#x200B;**](../features-and-workflows/quick-actions.md)**的更多信息。**
* 快速向图层栈叠添加滤镜：
  * **裁剪：**&#x200B;使用&#x200B;**2D 视图**&#x200B;中的手柄裁剪图像和材料。
  * **变换：**&#x200B;更正&#x200B;**2D 视图中手柄的透视错误。**
  * **变换：**&#x200B;调整&#x200B;**2D 视图中带手柄的图像和材料的大小。**
  * **仿制图章：**&#x200B;**2D 视图**&#x200B;中的绘画区域用于修复接缝或其他问题。
* 关闭以下面板后，请重新打开这些面板：
  * [**快速操作面板**。](panels/quick-actions-panel.md)
  * [**项目面板**。](panels/project-panel.md)
  * [**资源面板**。](panels/assets-panel.md)
  * [**通道设置面板**。](panels/channel-settings-panel.md)

有关&#x200B;**左侧边栏**&#x200B;中可用滤镜的更多信息，请参阅[工具和小组件](tools-and-widgets/tools-and-widgets.md)。

## 右侧边栏

**右侧边栏**&#x200B;在关闭以下面板时包含这些面板：

* [**图层面板**。](panels/layers-panel.md)
* [**属性面板**。](panels/properties-panel.md)
* [**公开参数面板**。](panels/exposed-parameters-panel.md)
* [**物理尺寸面板**。](panels/physical-size-panel.md)
* [**元数据面板**。](panels/metadata-panel.md)
* [**导出面板**。](panels/share-panel.md)
