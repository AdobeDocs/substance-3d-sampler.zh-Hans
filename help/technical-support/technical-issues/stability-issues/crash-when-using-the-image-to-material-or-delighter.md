# 使用图像材料或取乐时崩溃

**图像到材料（AI支持）**&#x200B;和&#x200B;**Delighter**&#x200B;滤镜需要大量可用的VRAM（至少1GB）。

如果您的GPU卡只有2GB可用的VRAM，并且使用的是2K/4K分辨率，我们将无法分配足够的内存来执行滤镜，并且可能会发生崩溃。
