# 导出素材时崩溃

导出在Sampler中创建的素材时，可能会在导出时崩溃。 发生崩溃通常是因为开始导出过程时GPU上缺少VRAM（尤其是使用Delighter滤镜的素材）。

降低导出分辨率并关闭任何其他应用程序可能有助于释放一些内存，以便完成导出。
