# 导出材料时崩溃

导出在Sampler中创建的材料时，可能会发生导出时崩溃。 此崩溃通常是由于开始导出过程时GPU上缺少VRAM所致（尤其是对于使用delighter滤镜的材料）。

降低导出分辨率并关闭任何其他应用程序可能有助于释放一些内存，以便完成导出。
