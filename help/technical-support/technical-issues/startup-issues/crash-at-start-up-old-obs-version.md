# 启动时崩溃 — 旧OBS版本

由于安装了旧的[OBS](https://obsproject.com/fr)版本，应用程序可能会在启动时崩溃。

要解决此问题，请更新[OBS版本](https://obsproject.com/fr/download)或卸载。
