# 字体无法正确显示

如果您使用的是Windows 10企业版并且使用[阻止不受信任的字体功能](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise)，则可以按照此[教程](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html)进行操作，以将Sampler从不受信任的应用程序列表中排除，从而阻止字体。
