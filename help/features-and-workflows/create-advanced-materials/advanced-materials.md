# 创建高级素材

借助[OpenPBR](../openpbr.md)，您可以使用[模糊](fuzz.md)、[次表面](subsurface.md)和[涂层](coating.md)等通道创建有趣的效果。 这些通道通常仅用于特定的上下文，其作用可能与常用的通道（如粗糙度或基色）稍有不同。

- [绒毛](fuzz.md)
- [次表面](subsurface.md)
- [涂层](coating.md)
