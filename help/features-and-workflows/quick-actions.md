# 快速操作

![](../assets/Quactooltip.png)

快速操作是一个系统，通过它，只需单击几下即可在堆叠中创建资源或添加多个图层。 使用快速操作创建资源、创建项目或将所需的图层添加到现有堆叠。

在Sampler中，您可以在多个位置找到快速操作：

* [主屏幕](../interface/the-home-screen.md)
* [创建新窗口](../getting-started/project-management.md)
* [快速操作面板](../interface/panels/quick-actions-panel.md)

| 快速操作名称 | 描述 | 图层 |
| --- | --- | --- |
| 将图像转化为材质 | 从单个图像中创建具有所有必要渠道的材料。 | 材料AI色调均化的输入图像 |
| 将多角度图像转化为材质 | 通过合并从不同光线角度拍摄的曲面照片来创建材料 | 输入多角度转材质均衡 |
| 导入纹理 | 从纹理图创建材质。 | 输入 |
| 导入图像 | 创建一个空材质，并添加一个图像作为图层。 | 输入 |
| 将图像转化为刺绣 | 应用程序化滤镜使图像看起来像刺绣补丁。 | 输入刺绣 |
| 创建织物材质 | 使用程序化滤镜创建织物材质。 | 布料 |
| 调整图像 | 选择过滤器以微调，并准备在素材中使用的图像。 | 输入裁剪拼贴亮度/对比度色相/饱和度颜色替换 |
| 创建空材质 | 创建没有渠道的材质。 | 无 |

## 如何使用快速操作

<b>从主屏幕</b>

单击快速操作

![](../assets/clickquickaction-ezgif.com-video-gif-converter.gif)

或者拖放快速操作的图像。

![](../assets/dndquickaction-ezgif.com-video-gif-converter.gif)

或者拖放快速操作的图像。

<b>从新建</b>

选择任何快速操作或导入文件，查看哪些快速操作可用于您的输入

![](../assets/createnew-1.png)

<b>从快速操作面板</b>

单击快速操作以将其添加到堆叠或创建新资源，具体取决于快速操作类型：

* <b>应用：</b>对活动堆叠应用快速操作。
* <b>设置：</b>打开设置窗口，以便在将快速操作添加到堆叠之前对其进行预排列。
* <b>创建新资源：</b>从所选快速操作创建新资源。
* <b>创建新项目： </b>从所选快速操作创建新项目。
