# 发送到任何应用程序

从Sampler 4.5版本中，您现在可以将资源从Sampler直接发送到任何已实施连接器的应用程序。\
它允许通过单击一次即可将资源从Sampler发送到第三方应用程序，从而避免必须手动执行导出和导入过程并节省时间。

今天，Send-to可以在Blender、Unreal Plugines、Unity、3ds Max和Maya中通过Substance增效工具使用引擎。

## 支持的应用程序版本

为了能够使用发送到，需要正确版本的Sampler、第三方应用程序和插件。

以下是您使用“发送到”功能所需的最低版本：

* <b>虚构引擎增效工具</b>
  * 完全支持UE5.4之后的任何版本。
  * *已在UE Marketplace上发布*

* <b>Maya插件v3.0.0+</b>
  * 在Maya 2025、2024、2023和2022中受支持
  * *自2025年Maya后开箱即可使用，对于之前的版本，需要从[网站](https://www.adobe.com/products/substance3d/plugins/substance-in-maya.html "Maya网页中的Substance")*&#x200B;下载增效工具

* <b>3ds Max Plugin v3.0.0+</b>
  * 在3ds Max 2025、2024、2023和2022中受支持
  * *自3ds Max 2025起开箱即用，对于早期版本，需要从[网站](https://www.adobe.com/products/substance3d/plugins/substance-in-3ds-max.html "在3ds Max网页中Substance")*&#x200B;下载增效工具

* <b>Unity Plugin v3.11+</b>
  * Unity版本2022、2021或2020
  * *需要从Asset Store下载插件*

* <b>Blender插件v2.1+</b>
  * Blender 3.0及更高版本
  * *插件可在[网站](https://www.adobe.com/products/substance3d/plugins/substance-in-blender.html "Blender网页中的Substance")*&#x200B;上下载
