# 环境变量

此页列出可用于覆盖应用程序的默认行为的环境变量。

| 变量 | 描述 |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_LICENSE** | 值： license.key文件的路径覆盖应用程序加载许可证文件的位置。  **注意：**&#x200B;低于3.0的版本使用此变量名称：**SUBSTANCE\_ALCHEMIST\_许可证** |
