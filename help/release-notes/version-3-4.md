# 版本3.4

**Substance 3D Sampler 3.4.0**&#x200B;引入了一系列旨在提高3D工作流程速度和质量的新功能。

*发行日期：2022年9月6日*

## 主要功能

## 公开的参数

在任何支持SBSAR文件的软件中修改参数材料，例如CLO、UE5、Blender、Photoshop和Illustrator等。\
这一点现在成为可能，这要归功于公开资源参数的新功能，它允许您加快迭代并消除Sampler和其他软件之间的干扰和冲突。

只需单击大头针即可公开材料的参数。

色点可帮助您导航到公开参数和各面板。

## Python创作

您现在可以创建插件和脚本，这使您能够自定义界面，从而轻松将Sampler集成到您的Pipeline中，并以您想要的任何方式设置您的整体工作流程。\
例如，您可以创建一个脚本，以便在一键导出多个材料时自动执行重复性任务。

了解如何在[此处](../scripting-and-development/scripting-and-development.md)创建您的第一个插件或脚本。

## CLO物理属性

现在，您可以通过物理模拟创建具有逼真行为的纺织品。 这可以通过输入织物的物理属性（例如弯曲、剪切和摩擦）来实现。\
通过此次更新，SBSAR将在其元数据中包含物理信息，CLO将使用这些信息来确保材料做出逼真的反应。

## 图像到材料（AI支持）

现在，可在MacOS上使用“图像到材料”（由AI提供支持），并且可在Apple Silicon设备上原生运行。
