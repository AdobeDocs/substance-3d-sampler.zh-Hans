# 0.6.0

发行日期：**2019/04/18**

已添加：

* [元数据]在专用选项卡中查看和填充素材元数据
* [收藏夹]直接从搜索结果创建收藏夹
* [Media Publishing]导出收藏夹展示板
* [UX]通过按Ctrl+Z撤消微调更改或图像导入
* [UX]通过按Ctrl+Shift+Z重做扭曲更改或图像导入
* [UI]具有新样式的新图标
* [性能]新的会话管理器可更好地处理选项卡切换
* [性能]更快地打开图像导入图层
* [内容]新的金属类通用材料
* [内容]新铁锈材料
* [内容]新石材类通用材料
* [内容]浮雕滤镜更新
* [内容]刺绣滤镜更新
* [内容]绘画滤镜更新
* [内容] Delighter滤镜更新

已修复：

* [内容]水滤器正在以Specular/光泽度工作流程运行
* 在激活弹出窗口中修复灰度单选按钮
* 接受包含昏迷字符的文件
* 修复弹出窗口上的小字体问题
* 修复由于与某些NVIDIA显卡的FXAA参数冲突而导致的透明度UI问题
* 在滑块中输入值后移除字段的焦点
* 将最小VRAM量分配给喜爱的内容以减少崩溃
* 修复了调整应用程序窗口大小时窗口冻结的问题
* 修复了在评估时删除图层栈栈时发生崩溃的问题

已知问题：

* 不建议在一个素材中使用多个喜悦
* 使用较旧的NVIDIA驱动程序（低于400.x）时Delighter崩溃
* 不建议使用“愉悦”阶段的快速可见性切换
* 自定义环境导入可能会变成黑色
* Tif图像未显示在“图像导入”图层的“属性”面板中
* 在滑块中键入特定值时，可以忽略昏迷或点
