# 0.5.0

发行日期：**2019/02/28**

已添加：

* [图层堆叠]图层重新排序
* [图层堆叠]删除隐藏图层
* [图层堆叠]直接在您选择的位置导入材料
* [图层堆叠]作为新筛选器参数类型的材料输入
* [性能]为获得更好的性能，Substance 引擎预算是动态的
* [性能]更好的OpenGL性能，特别是在MacOS上
* [数据]新版本发布后数据升级速度更快
* [内容] Windows 7和Windows 8上提供AI Delighter
* [内容]可在RTX GPU上使用AI Delighter

已修复：

* 在退出应用程序时修复可能的崩溃
* 导出大型收藏夹时，导出弹出窗口打开速度更快

已知问题：

* 不建议在一个材料中使用多个喜悦
* 使用较旧的NVIDIA驱动程序（低于400.x）的Delighter崩溃
* Delighter阶段的快速可见性切换会影响性能
* 加载您自己的环境时崩溃
