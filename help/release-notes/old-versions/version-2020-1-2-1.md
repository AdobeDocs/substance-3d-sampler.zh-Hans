# 版本2020.1 (2.1)

**Substance Alchemist2020.1“Tiramisu”**&#x200B;允许您导出直接打包的材料，供渲染器和游戏引擎使用。 默认情况下，有15种导出预设可用，例如Unity HDRP、虚构引擎4、Blender、Vray-Next等。

它具有新的配置文件和更新检查器的控件。

发行日期：*2020年3月12日*

## 主要功能

### “新建导出器”窗口

![](../../assets/header-exporter.png)

重新设计了导出窗口，以引入新的界面，该界面具有以下新增功能：

* **使用导出预设为特定渲染器或游戏引擎打包纹理**&#x200B;现在，您可以在导出过程中从一系列导出预设中选择配置，这些预设可转换、打包和命名特定第三方应用程序的纹理。 转换的结果显示在界面右侧的通道列表中。\
  默认情况下，新导出器包括以下预设：

  * 虚线引擎4
  * Unity Standard
  * Unity HDRP
  * 混合器循环/平均
  * Arnold 5
  * Corona渲染
  * Enscape
  * Keyshot 9
  * Redshift
  * 查看下一个
  * Lens Studio
  * Spark AR Studio
  * PBR金属粗糙度中的PBRSpecular/光泽度

  ![](../../assets/exporter-preset-list.png)
* **创建名为材料的子文件夹**\
  将多个材料导出到公共位置时，现在可以创建子文件夹
* **导出设置已保存，并已通过下次导出还原**\
  为方便起见，重新打开导出窗口时，也会重复使用以前使用的导出设置。 更轻松、更快速地重新导出材料。
* **创建、导入和管理自定义导出预设**\
  也可以创建自定义导出预设。 要了解如何创建和管理它们，请查看以下文档页面：

  * [管理自定义预设](https://helpx.adobe.com/substance-3d/unlisted/documentation/sadoc/creating-and-importing-custom-presets-188976295.html)
  * [管理预设](../../getting-started/export/managing-presets.md)

### 应用程序配置

![](../../assets/header-config.jpg)

（由[Fabian Grohs](https://unsplash.com/@grohsfabian?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText)拍摄于[闪屏](https://unsplash.com/?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText)）

现在可以使用配置文件配置Substance Alchemist。 这样可以更轻松地跨计算机设置应用程序，例如在工作室中。 配置文件定义默认资源和链接的文件夹列表。

要了解有关如何创建和使用配置文件的更多信息，请参阅专用的[文档页面](https://helpx.adobe.com/substance-3d/unlisted/documentation/sadoc/resources-configuration-file-188976187.html)。

### 其他改进

![](../../assets/header-checker.png)

此版本中提供了一些新的工作流程改进：

* **2D 视图的焦点**\
  现在可以使用“F”快捷键重置视图和将2D 视图居中，这与3D视图相同。
* **重新打开最后一个项目**\
  为了更轻松、更快速地创建内容，应用程序现在会重新打开上次使用的项目。 现在，创建实验室也是打开应用程序时的默认模式。
* **更新检查器配置**\
  定义是否有新版本可用时通知您。 有关详细信息，请参阅专用的[文档页面](../../technical-support/configuration/update-checker.md)。

### 新内容

![](../../assets/header-content.jpg)

我们改进了部分过滤器，并更新了入门内容：

* **新初学者材质**\
  我们用新字体替换了一些现有材料，以下是新材料的列表：
  * 阿尔坎塔拉微纤维
  * 地毯Floor
  * 悬崖摇滚
  * 铜
  * Dirt破裂
  * 粗剪
  * 特拉科塔
  * 羊毛织物
  * 织物
* **具有位图2材质过滤器的金属控件**\
  “位图2”材质过滤器已更新，可提供对金属通道的更多控制。 现在可以使用自定义位图输入或定义统一颜色。
* **改进的调整滤镜**\
  “调整”筛选器现在可处理项目集，以使用PBR工作流程Specular/光泽度。
* **新Atlas Scatter参数**\
  我们添加了一些新参数，以便更好地控制元素如何与以下材料的高度图混合。
