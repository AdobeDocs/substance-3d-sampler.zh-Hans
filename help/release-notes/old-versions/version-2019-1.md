# 版本2019.1

**Substance Alchemist2019.1“芝麻”**&#x200B;允许您与其新项目管理共享您的资源。 图层堆叠已完全重建，以改进工作流程。 视口中添加了其他控件和信息。 我们欢乐的新版本提高了您材料的质量和准确性。

发行日期： *4 2019年11月*

>[!NOTE]
>
> **注意：**&#x200B;使用Beta版0.8.1或更低版本制作的内容与版本2019.1不兼容。 但是，不会丢失任何信息，并且仍然可以通过启动0.8.1版来访问这些数据。

## 主要功能

### 新的“欢迎”屏幕

![](../../assets/sa-notes-welcomescreen.jpg)

“Substance Alchemist”现在有一个欢迎屏幕，可让您快速启动最新项目或创建新项目。 欢迎屏幕还提供了一些指向现有平台的链接，例如[Substance学院](https://academy.substance3d.com/)。

### 项目管理

![](../../assets/sa-notes-openproject.png)

2019.1版引入了可以收集材料集合的项目概念。 项目也可以导出以共享到其他计算机。

要了解有关项目的更多信息，请参阅： [项目管理](../../getting-started/project-management.md)。

### 新欢乐

![](../../assets/sa-notes-delighter.jpg)

我们改进了快乐功能，用于消除照片中的阴影。 现在，它可以保留各种表面的细节和原始颜色，从而可以提高所生成材料的精度。

### 新建图层堆叠

![](../../assets/sa-notes-layerstack.png)

该图层堆叠从零开始重建，以扩大其可能性和行动。 显着变化包括：

* **现在可以通过其专用图标直接访问材料和蒙版**\
  现在，在图层堆叠中添加材料时，它将有一个新的蒙版图标。 单击第二个图标将显示材料的混合参数。

  ![](../../assets/sa-notes-layermask.png)
* **可以直接从工具栏更改混合模式**\
  从现在起，当选择材料图层时，可以直接从图层堆叠工具栏中更改其混合模式，而无需单击蒙版。

  ![](../../assets/sa-notes-layerstackblendmode.png)
* **将位图分配给特定的扫描输入**\
  导入位图以从扫描创建材料时，您可以为每个位图指定正确的用法。

  ![](../../assets/sa-notes-scanusage.png)

### 视口改进

![](../../assets/sa-notes-viewport.jpg)

视口中添加了一些新功能，提高了其利用率。 可以在[查看器设置面板](https://helpx.adobe.com/substance-3d/unlisted/documentation/sadoc/viewer-settings-188973164.html)中访问这些新设置。

* **相机模式**\
  投影模式允许在透视和正交之间进行选择。

  ![](../../assets/sa-notes-cameramode.png)
* **视角**\
  您现在可以更改视口的相机视角(FOV)。 调整此值有助于真实地显示材料。 视角只能在透视投影模式下控制。

  ![](../../assets/sa-notes-viewport-fov.png)
* **每个通道的分辨率和位深度**\
  2D 视图现在会显示纹理分辨率以及每个声道的位深度。

  ![](../../assets/sa-notes-2dviewresolutiondepth.png)
