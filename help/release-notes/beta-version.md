# Betas

此页包含Sampler Beta版的更改日志。 在[常见问题解答](../faq.md)中了解如何访问测试版。

>[!NOTE]
>
>Sampler的Beta版并非始终可用。 要了解未来何时发布测试版，请关注Substance 3D社交渠道。


## 4.4.0测试版 — 纹理化文本

我们即将引入由Adobe Firefly支持的文本到纹理功能，这是一种全新的方法，艺术家只需使用描述即可获取纹理图像。 这项新功能通过提供直接在Sampler中生成纹理的方法，扩展了艺术家工具箱，而不仅仅是导入自定义摄影作品或库存摄影。 所有“文本到纹理”图像都是方形的，具有适当的透视效果并可以平铺，为材质创建工作流程做好准备。

![](../assets/wood-ui.png)

*（发布日期：2024年4月9日）*

<b>已添加：</b>

* [Firefly]从提示生成可平铺纹理
* [Firefly]在第一代后生成更多变体
* [Firefly]将结果作为图层添加到“您的资源”库中
* [Firefly]浏览以前提示的历史记录
* [Firefly]生成的图像包含具有来源的清单
