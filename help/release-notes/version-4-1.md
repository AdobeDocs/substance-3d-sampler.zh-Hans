# 版本4.1

<b>Substance 3D Sampler 4.1.0 </b>引入了<b>绘画变形</b>滤镜的新内容和<b>刺绣</b>滤镜的改进版本。 此更新包含一些3D 捕捉改进。

*发行日期：2023年3月28日*

## 绘画变形

绘画变形滤镜允许您通过在2D 视图上绘制曲线来变形材料。\
“拉直”选项允许您重新调整材料，以便实现无缝的拼贴工作流程。

## 刺绣

新的刺绣生成器可让您通过单个图像矢量文件或绘图创建刺绣补丁。\
本发明可刺绣多达6种颜色，结合多种缝合工艺。
